# PytestAndActionsTest
Repository for experimenting with Python unit testing and implementing CI/CD pipelines using GitHub Actions.

# Overview
This repository contains a simple Python project that demonstrates the use of Pytest for unit testing and GitHub Actions for continuous integration and deployment. The project includes a basic Python script and corresponding test cases to illustrate the testing process.

# Getting Started
To get started with this project, follow the steps below:
1. Clone the repository to your local machine.
2. Create a new virtual environment.
3. Install the required dependencies using the provided `requirements.txt` file:
   ```
   pip install -r requirements.txt
   ```
4. Run the tests using Pytest:
    ```
    pytest
    ```
5. Explore the GitHub Actions workflow defined in the `.github/workflows` directory to understand how CI/CD is set up for this project.
6. Modify the code and tests as needed, and observe how the CI/CD pipeline responds to changes.
